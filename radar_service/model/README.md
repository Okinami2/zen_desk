# 🚀 雷达 1D-CNN 动作识别模型训练与纯 C 部署指南

本目录（`model`）包含了雷达信号特征提取、状态分类模型（1D-CNN）的训练代码，以及独创的**纯 C 语言部署方案**。

🎉 **最新重大成果**：
我们彻底摒弃了复杂的华为 NPU（ATC工具链）和 `.om` 模型转换流程。我们实现了一个**纯粹依赖 CPU 的 C 语言数学推理引擎**，能在 1 毫秒内完成深度学习前向传播计算，**零第三方库依赖，百分之百兼容交叉编译**！

---

## 📁 目录结构说明
* `train.py`: 核心模型定义与训练脚本。
* `test_model.py`: 在 PC/虚拟机端快速验证模型准确率的测试脚本。
* `export_c_weights.py`: **【核心】** 模型参数导出工具。它负责将 PyTorch 模型 (`.pth`) 的权重提取并进行底层数学融合（如 Conv+BatchNorm），直接输出为 C 语言头文件。
* `radar_data.csv`: 您的训练数据集（真实采集数据）。
* `test_data.csv`: 您的验证测试数据集。
* `../src/radar_model_inference.c`: 我们手写的纯 C 语言 1D-CNN 推理引擎。

> [!NOTE]
> **关于未来模型的扩展 (NPU / .om 方案)**
> 目前我们采用的是零依赖的纯 C CPU 推理方案，这对于当前的轻量级 1D-CNN（2 层卷积 + 2 层全连接）来说是速度最快、开发成本最低的最优解。
> 
> **未来的可能性**：如果后续雷达模型大幅度膨胀（例如引入了深层 ResNet 甚至 Transformer，计算量激增），纯 C 方案可能会遇到 CPU 性能瓶颈。届时，我们可以重新启用华为海思的 NPU：
> 1. 在 `train.py` 训练后，通过 PyTorch 导出 `.onnx` 格式。
> 2. 使用华为的 **ATC 工具**将 `.onnx` 转换为 `.om` 模型文件。
> 3. 在底层的 C 代码中引入海思的 `ACL` 库，通过 NPU 加速执行该 `.om` 模型。

## ⚙️ 模型原理解析
* **输入特征**：`(32通道, 10时间步)`。雷达 16 个距离门的运动能量 + 16 个静止能量。滑动窗口收集过去 10 帧（约 1 秒）。
* **网络结构**：轻量级 **1D-CNN (一维卷积神经网络)**，包含 Conv1d、MaxPool1d 和 Linear 全连接层。
* **输出分类**：3 个概率值（`0: AWAY 离开`, `1: NORMAL 正常在座`, `2: FIDGET 乱动`）。
* **判定逻辑**：1秒内多数表决 + 连续 5 秒稳定过滤，极其抗干扰。

## 🏃‍♂️ 极简工作流：如果模型不准，如何重新训练和部署？

当您发现雷达在特定场景（比如站椅子背后）识别不够准时，只需遵循以下 **三步走** 即可完成 AI 升级，全过程不到一分钟！

### 第一步：重新训练模型
确保您的 `radar_data.csv` 已经加入了新的场景数据，然后在 `model` 目录下执行：
```bash
python3 train.py --epochs 50 --batch 32
```
*训练完成后，会生成新的 `radar_model.pth` 权重文件。*

### 第二步：一键导出 C 语言大脑
继续在 `model` 目录下执行：
```bash
python3 export_c_weights.py
```
*这个脚本会立刻将新的大模型知识“注入”到 `../src/radar_model_weights.h` 文件中。您完全不需要去管任何 ONNX 或 NPU 模型转换！*

### 第三步：重新编译主程序
回到 `radar_service` 的顶级目录，重新执行编译命令：
```bash
cd ..
make clean && make
```
**大功告成！** 新的 AI 模型已经被硬编码进了您的 `radar_service`，赶紧跑起来试试吧！

## 📥 如何采集更多极端场景数据增强模型？

为了让模型变聪明，最有效的方法就是“投喂”它以前没见过的数据。我们已经为您准备好了非常方便的数据采集工具。

假设您发现在**“站在座椅后面”**时模型容易误判，您需要录制这个特定场景作为 `AWAY (0)` 标签的数据：

1. **登录海鸥派板子终端**。
2. 进入编译输出目录 `out/bin`。
3. 执行采集指令，语法为：`./radar_collect <标签> <持续帧数> <保存路径>`
   ```bash
   # 录制标签为 0，持续 600 帧（约 2 分钟），数据追加保存到当前目录 (out/bin)
   ./radar_collect 0 600 radar_data.csv
   
   # 录制标签为 1，持续 600 帧（约 2 分钟）
   ./radar_collect 1 600 radar_data.csv
   
   # 录制标签为 2，持续 180 帧（约 30 秒）
   ./radar_collect 2 180 radar_data.csv
   ```
4. 按照上述指令，分别在无人、在座、乱动时录制特征。
5. （可选）录制多组不同姿态的数据，它会自动追加在同一个文件里。
6. 将板子上的 `out/bin/radar_data.csv` 拷贝回虚拟机，**把里面的数据行直接追加拷贝到** 您原本的 `model/radar_data.csv` 文件的末尾。
7. 回到上面的 **【极简工作流】** 重新训练一遍。

**从此以后，您可以无限给模型“喂”数据，让它成为一个永远不会认错人的终极智能雷达！**

收集数据用以下指令：

./radar_collect 0 600 /tmp/radar_data.csv  无人
./radar_collect 1 600 /tmp/radar_data.csv  有人
./radar_collect 2 180 /tmp/radar_data.csv  乱动
